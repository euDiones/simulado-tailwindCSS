# 📚 Projeto de Estudo Front-End - uniSenac

Projeto acadêmico desenvolvido como parte dos estudos de desenvolvimento web no curso de **Análise e Desenvolvimento de Sistemas** da **uniSenac**.

O objetivo do projeto é a prática de recriação de interfaces responsivas, estruturação semântica em HTML5 e estilização moderna com Tailwind CSS v4.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação de marcação e tags semânticas[cite: 4].
* **Tailwind CSS (v4)**: Framework CSS utilitário para estilização e layout responsivo.
* **Google Fonts**:
  * [Bai Jamjuree](https://fonts.google.com/specimen/Bai+Jamjuree)[cite: 5]
  * [Inter](https://fonts.google.com/specimen/Inter)[cite: 5]
  * [Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch)[cite: 5]

## 📁 Estrutura de Arquivos

```Simulado
├── img/                # Imagens, vetores e ícones da aplicação
